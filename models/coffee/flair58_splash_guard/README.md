# flair58_splash_guard — 플레어 58 후방 스플래시 가드

> **상태: 계획 확정. 모델링 착수 대기.**

## 목적/용도

Flair 58 로 추출할 때 **주로 포터필터에서** 새는 커피가 주변 벽에 튀어 오염된다.
뒤쪽을 ㄷ 자로 감싸는 벽을 세워 막는다.

벽이 서 있도록 **바닥 발을 일체로** 만들고, 안쪽 혀가 실리콘 매트 밑에 깔려 고정된다.

## 확정 사양

| 항목 | 값 | 근거 |
|---|---|---|
| 벽 높이 | 200 | 누출이 주로 포터필터 → 이 높이면 충분 (사용자 판단) |
| 벽 두께 | 2.5 | 0.5 압출폭 기준 벽 5줄 — 인필 없이 꽉 참 |
| 안쪽 폭 | 300 | 매트 폭과 일치 |
| 옆벽 길이 | 150 | 매트 450 의 1/3 |
| 재료 | **PETG** | PLA(Tg 60°C)는 추출 93°C 에 부적합 |
| 끼움 공차 | 0.3 (한쪽당) | 200mm 슬라이드 구간이라 여유 필요 |
| 전원선 홈 | 8.0 폭 × 30 깊이 | 전선 Ø6.5, 최대 36° 기울기 허용 |

### 전원선 홈 (왼쪽 파트에만)

Flair 의 전원선을 빼내기 위해 **왼쪽 옆벽 윗면에서 파 내려오는 홈**을 둔다.
두 파트가 비대칭이 되는 이유가 이것이다.

| 항목 | 값 |
|---|---|
| 위치 | 왼쪽 옆벽, **뒷벽 안쪽 면에서 앞으로 50** |
| 깊이 | 상단에서 아래로 30 (홈 바닥 z=170) |
| 폭 | **8.0** (전선 Ø6.5 + 여유 1.5) |
| 바닥 형상 | R4 반원 — 전선 형상에 맞고 응력 집중이 덜함 |

폭 8.0 은 전선이 벽에 대해 **최대 36° 까지 기울어도** 들어가는 값이다
(필요 폭 = 6.5 / cos θ). 비스듬히 끼운다는 조건을 반영했다.

**출력상 문제 없음** — 세워서 뽑으면 벽이 z=170 까지 정상적으로 올라가다가 그 위로
홈만큼 비는 구조다. 홈 바닥은 위를 향한 바닥면이라 오버행이 아니다.

> 홈은 벽 상단(z 170~200)에 뚫린 구멍이라 이론상 튐이 새어나갈 수 있다. 다만 가장
> 높은 구간이라 튈 일이 적고 전선이 홈을 대부분 메운다. 문제가 되면 덮개를 추가한다.

### 파트 구성 — ㄱ자 2개

ㄷ 자를 반으로 쪼개 **옆벽 + 뒷벽 절반을 한 파트로** 뽑는다.

- 코너가 일체가 되어 **자립 안정성이 크게 오른다**
- 코너 커넥터 2개가 불필요해진다
- 세워서 출력하므로 **발판도 일체**로 붙는다 (바닥 플랜지가 베드에 깔림)
- 출력 중에도 두 면이 직각으로 서로 버텨 **평판보다 흔들림이 적다**

중앙 이음은 **텅 & 그루브 일체** — 왼쪽 파트 끝에 텅, 오른쪽 파트 끝에 홈. 별도 부품 없음.
두 파트는 미러가 아니라 각각 다른 모델이다 (왼쪽에만 전원선 홈이 있어 비대칭).

- **왼쪽 파트** = 왼쪽 옆벽 150 + 뒷벽 왼쪽 절반 150 + 전원선 홈 + 텅
- **오른쪽 파트** = 오른쪽 옆벽 150 + 뒷벽 오른쪽 절반 150 + 그루브

좌/우는 **사용자가 앞에서 기기를 바라볼 때** 기준이다.

### 발 단면 (조리대 z=0 기준)

```
        │ 벽 2.5 × 200
        │
   ┌────┤
   │ 4  │
   └────┴──┐ 혀 1.5
  -40    0 └──────╲  ← 끝 5mm 램프
            2.5  12.5
   바깥 플랜지      안쪽 혀
   (조리대 위)      (매트 밑)
```

- **바깥 플랜지 40 × 두께 4** — 매트 바깥 조리대에 놓인다. **매트를 전혀 안 들어올림**
- **안쪽 혀 10 × 두께 1.5** — 매트 밑으로 들어가 붙잡는다. 끝 5mm 는 램프로 완만하게

> 발판을 앞뒤로 나눈 이유: 혀만 10mm 로 두면 매트가 눌러주는 무게가 **10.8g** 에
> 불과하고 **2.9° 만 기울어도 넘어간다**. 안정성은 바깥 플랜지가, 고정은 안쪽 혀가
> 담당하게 해서 "매트가 들리는 면적 최소화" 라는 요구를 유지했다.

## 출력

| 항목 | 값 |
|---|---|
| ㄱ자 1개 평면 bbox | 190 × 190 |
| 높이 | 200 |
| 베드 256×256×256 | ✅ 여유 |
| 서포트 | 불필요 (두 벽 수직, 발 플랜지는 베드에 깔림) |
| 재료 | ㄱ자당 PETG 257g / **2개 합 514g** |
| 시간 | 개당 약 4.7h / **합 약 9.4h** |
| 층수 | 1000층 (0.2 기준) |

조립 후 전체: **바깥 폭 305 × 옆벽 150 × 높이 200**

## 검토했으나 채택하지 않은 것

| 안 | 이유 |
|---|---|
| ㄷ자 일체 출력 | 베드 256 에 300 이 안 들어감 |
| 눕혀 출력 (15층, 빠름) | ㄱ자는 3차원이라 눕힐 수 없음. 세워야 코너·발 일체가 됨 |
| 별도 H채널 이음 (3파트) | 파트 대칭이면 미러로 이득이나, 어차피 비대칭이라 이점 없음 |
| 발 = 얇고 넓은 램프 | 매트 전 구간이 들림 |
| 발 = 혀 10mm 만 | 자립 불가 (2.9°) |
| PLA | Tg 60°C < 추출 93°C. 뜨거운 수분에 가수분해도 잘 됨 |

## 남은 확인 사항

- Flair 58 바닥 치수 — 옆벽 150 안에서 기기 출입이 실제로 편한지
- 매트 두께는 확인 불필요 (사용자 판단: 혀 1.5mm 단차는 신경 쓸 수준 아님)

## 작업 단계

1. 측정 · 결정 ✅ 완료
2. **발 부분만 시험 출력** — 혀 1.5mm 가 매트에서 실제로 괜찮은지 먼저 검증
   (전체는 9.4시간짜리라 다 뽑고 나서 고치면 손해가 크다)
3. ㄱ자 파트 모델링 + iter
4. 최종 출력 · 조립
