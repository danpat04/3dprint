# monitor_stand

휴대용 모니터를 안정적으로 거치하기 위한 커스텀 분리형 스탠드.
모니터 뒷면 M4 나사홀 2개를 활용해 결합, 분리 시 휴대 가능하도록 4파츠 모듈식 구조.

## 목적/용도
- 23.8" 휴대 모니터(2.15kg)의 기본 거치 안정성 보강
- 분리해서 모니터와 함께 휴대
- 출력은 측면 lying — 모든 파츠 X 두께 통일 (20mm)

## 모니터 사양 (기준)
| 항목 | 값 |
|---|---|
| 크기 | 23.8 인치 |
| M4 나사홀 개수 | 2개 (가로 1줄) |
| 나사홀 간격 | 74.4mm |
| 나사홀 깊이 | 4.1mm (실측) |
| 나사홀 ~ 모니터 바닥 | 87mm |
| 모니터 두께 | 20.7mm |

## 파츠 구성

| 파츠 | 수량 | 용도 |
|---|---|---|
| **t_piece** | 2 | 뒤집힌 T (세로 기둥 + 가로 받침), M4 홀로 모니터 결합 |
| **pillar** | 2 | 두 T 를 잇는 가로기둥. 하나는 기둥 상단, 하나는 받침 후방 |

총 4파츠. 자석 6개(슬롯당 1+1, 4슬롯) 매립.

## 치수 / 좌표계
- X: 모니터 좌우 (M4 홀 간격 방향)
- Y: 모니터 두께/깊이 (모니터→스탠드 뒤쪽)
- Z: 수직 (책상=0)

### t_piece
| 항목 | 값 | 비고 |
|---|---|---|
| 세로 기둥 단면 | 20×20mm | X×Y |
| 세로 기둥 높이 | 142mm | 책상부터 |
| 가로 받침 폭 | 20mm | X (기둥과 통일 — 측면 lying 출력) |
| 가로 받침 깊이 | 200mm | Y (앞 140 + 뒤 60) |
| 가로 받침 두께 | 20mm | Z |
| 모니터 바닥 클리어런스 | z=40mm | 받침 위 20mm |
| M4 through-hole | Ø4.5 + Ø8×5 counterbore | 책상 위 z=127mm |
| 슬롯(상단) | 15.1 × 15.1 × 10mm | 기둥 내측면, z=100mm |
| 슬롯(받침) | 15.1 × 15.1 × 10mm | 받침 내측면, y=180mm |
| 자석 홈 | Ø5.1 × 5.1mm | 슬롯 끝, 각 1개 |

### pillar
| 항목 | 값 | 비고 |
|---|---|---|
| 단면 | 15×15mm | square |
| 길이 | 74.4mm | M4 홀 간격과 동일 (양쪽 10mm 삽입) |
| 자석 홈 | Ø5.1 × 5.1mm | 양 끝, 각 1개 |

## 결합 방식
- 슬롯 (15.2×15.2×10mm) 에 pillar 끝 (15×15) 삽입 — 양쪽 0.1mm 공차로 lateral 고정
- 슬롯 깊은 면 + pillar 끝면에 Ø5×5 자석 1쌍 → 흡인력으로 조립 가이드 및 분리 방지

## acceptance criteria
- t_piece: 책상 위에 세웠을 때 안정적, M4 홀 위치 z=127mm 정확
- 받침 앞 140mm + 뒤 60mm 비대칭 — 무거운 23.8" 모니터의 앞 tipping 저항
- pillar: 양 끝이 T의 슬롯에 들어가 자석이 마주봐 흡착
- 결합 후 두 T 사이가 정확히 74.4mm 유지, 비틀림 저항
- 분리 가능: 자석 흡인력 < 손으로 빼는 힘

## 재료/공정 가정
- FDM 3D 프린팅, Bambu P2S (256³ 빌드 볼륨)
- 각 파츠 모두 256mm 안에 들어옴
- 자석: Ø5×5mm 원형 네오디뮴
- 나사: M4 × 15mm 반구머리 십자홈 (PH2) — head 두께 ~2.4mm
- 와셔: 평와셔 Ø9 × 0.5mm (head 와 column 사이)
- 드라이버: PH2 필립스 십자
