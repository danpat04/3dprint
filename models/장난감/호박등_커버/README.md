# 호박등 커버 (램프 55×65mm용)

## 목적/용도
스퀴즈 실리콘 램프(55×65mm, 위 고리)에 씌우는 할로윈 잭오랜턴 커버.

## 방식
온라인 티라이트 호박 STL(`feedback/dynia+led+2+stl.stl`)을 변형:
- 뒤쪽 문 구멍: 옆 갈비 무늬를 복사해 메움
- 벽: 1.2mm 껍질로 얇게 (원본 안쪽 구조 제거)
- 꼭지 제거, 위에 Ø18 구멍(램프 고리 노출)
- 아래 개방 (개구부 내경 약 50mm, 램프 최대 지름보다 작게 → 말랑한 램프가 끼워짐)
- 바닥: 둥근 아랫면을 높이 6mm 잘라 평평한 림면 확보(링 추가 없음), 내경 49mm 원통 보어 높이 3mm
- 원본 비율 유지(균일 0.5배): 외경 약 70mm, 높이 약 48.5mm
- 아래 개구부 외경 약 52mm(내경 약 49.6mm): 램프(55mm)보다 작아 끼움

## 파일
- `model.py` 전체 실행 (work/rmap → maps → build → 렌더/STEP/STL)
- `exports/호박등_커버.stl` 출력용. 패널도 이 STL 을 그대로 쓴다

**STEP 은 내보내지 않는다.** 처음부터 메시인 모델이라 삼각형마다 B-rep 면을 만들어야
하는데, 그렇게 나온 103MB STEP 을 **뱀부랩이 로딩하지 못했다** (실사용 확인). 같은 모델의
STL 은 바로 열린다. 패널의 변환도 제한 시간을 넘겼다. 쓸 데가 없어 생성 코드를 지웠다.

## 상태
